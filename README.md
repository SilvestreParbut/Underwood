# Underwood-English

It is a rich-text processor for the Linux console (Debian and derivatives).

Underwood distinguishes itself from other terminal-based text editors by supporting bold, italics, underlining, page breaks, and find-and-replace functions.

Its native format is .RTF, chosen for its simplicity and broad compatibility across word processors; it also supports exporting to .PDF.

It is controlled via keyboard and mouse; the trackpad or mouse wheel can be used to scroll through content, while the mouse or trackpad allows for click-and-drag text selection.

Common options are displayed at the bottom of the terminal window, ensuring that commands and their descriptions remain easily accessible to the user.

Upon installing the `underwood-1.0.deb` file, the program is added to the distribution's menu under the "Accessories" category; it can be located via the application search function using the name "Underwood," and its icon is inspired by a typewriter.

The program's interface is currently in Spanish and supports all characters specific to the language, including "ñ," "¡," "¿," and accented characters; it can be adapted to other languages ​​by modifying the interface within the `.py` file.

# Underwood-Español

Underwood es un procesador de texto enriquecido para la consola de sistemas linux (debian y derivados)

Se diferencia de los demás editores de texto para la terminal al poseer capacidad para negrita, cursiva, subrayado, salto de página, búsqueda y reemplao de palabras.

Su formato nativo es .rtf, ya que es simple y altamente soportado por todos los procesadores de texto. Puede exportar como .pdf

Se controla con teclado y ratón, el trackpad o rueda del mouse pueden hacer scroll en el contenido, el ratón o trackpad puede hacer click y arrastrar para seleccionar el texto.

Las opciones comunes se encuentran en la parte baja de la terminal, de forma que el usuario siempre tenga a mano los comandos y sus descripciones.

Al instalar el archivo underwood-1.0.deb se asocia al menú de la distribución, quedando en la categoría de accesorios, puede buscarse en el buscador de aplicaciones como underwood, su ícono está inspirado en una máquina de escribir.

La interfaz programa actualmente está en español, tiene soporte para todos los simbolos de nuestro idioma incluyendo "ñ" "¡" "¿" y tildes. puede portarse a otros idiomas modificando la interfaz del archivo .py
